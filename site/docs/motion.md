# Motion

Quiet and quick: hover is a small surface step, never a colour jump, and transitions use the
fast duration.

Durations drop to 0 ms when someone asks for reduced motion (`prefers-reduced-motion: reduce`), so
a component that uses them needs no media query of its own.
