# Focus ring

Every focusable element shows the same ring when it is focused from the keyboard (WCAG 2.4.7),
links included. The ring sits on the edge of what is focused and follows its corners; a link in
text gets one ring per line when it wraps. Solid filled controls keep a small gap, so the ring
doesn't merge with their fill. The example uses Plinth's own buttons.

Click into the example and press Tab to see it. Switch the theme and the brand in the toolbar to
see it in dark and in the example brand.

<Canvas of={FocusRingStories.Demo} />

## The rule

Each component repeats these lines on its focusable elements. It is an outline, so forced-colours
mode keeps it, and it follows the element's border radius. The Storybook test runner tabs through
every story and fails if a focused element doesn't show this ring.
