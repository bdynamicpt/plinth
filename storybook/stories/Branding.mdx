# Plinth

_This page is a placeholder. Each section below gets its real content in its own issue._

## What Plinth is

Plinth is the design system of **b.dynamic**'s projects. It is design tokens, components written as
plain HTML and CSS, and thin Blade and Vue layers that print the same markup. A project brings its
brand through the tokens and never forks a component.

## Colours, and how a project brings its own

_To come: the palette and how to use it. In short, a project overrides the semantic tokens
(`--plinth-color-*`, `--plinth-radius-*`, `--plinth-font-family-body`) after Plinth's CSS. Switch
**Brand** in the toolbar to see the made-up example brand restyle every component:_

```css
:root {
  --plinth-color-accent: #0f766e;
  --plinth-radius-pill: 0.25rem;
}
```

See **Foundations → Colour** for the colours as they are today.
