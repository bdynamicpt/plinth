# Plinth

## What Plinth is

Plinth is the design system of **b.dynamic**'s projects. It is design tokens, components written as
plain HTML and CSS, and thin Blade, Vue and React layers that print the same markup. A project
brings its brand through the tokens and never forks a component.

## The guides are on the website

Installing Plinth, using it from Laravel and Filament, Vue, React and Tailwind, bringing a brand,
dark mode, the token tiers, the foundations, the component rules and the releases are documented
on Plinth's website, which serves this Storybook at `/storybook`:

- Start with the <Site to="introduction">introduction</Site> and the <Site to="installation">installation</Site>.
- Bring a brand: <Site to="branding">branding your project</Site> and <Site to="dark-mode">dark mode</Site>.
- The tokens: the <Site to="foundations">foundations</Site>.
- Why Plinth is the way it is: the <Site to="decisions">decisions</Site>, the ADRs in `docs/adr`.

Their Markdown is in `site/docs/` in the repository. Switch **Brand** in the toolbar to see the
made-up example brand restyle every component.
