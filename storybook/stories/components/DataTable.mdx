# Data table

A collection of records (orders, users, invoices) from one markup: a stack of cards on a phone,
a table from 768px up. The CSS alone changes the layout, so there is no script, and Blade and Vue
print the table once. Use it on custom pages and in the Vue site; Filament panels keep their own
tables.

## Markup

- **`plinth-data-table`**, the root, is the `<table>`; a project's classes and attributes land on
  it. The **caption** is optional: without one, name the table with `aria-label` or
  `aria-labelledby`.
- **The explicit roles** (`table`, `rowgroup`, `row`, `columnheader`, `cell`) are part of the
  contract. Some browsers, Safari in particular, drop a table's semantics once its rows stop
  displaying as table rows, which is what the phone's cards do.
- **`plinth-data-table-label`** repeats the column's name in each cell. It shows only on a
  phone's card and is `aria-hidden`, since the column header already names the cell. On a phone
  the header row stays in the accessibility tree, visually hidden, so every cell keeps its header.
- A wide table from 768px up belongs in a scrolling container the app adds; text wraps in its cell.

## Cards on a phone

Each row becomes a card: the **title** cell first, then each **field** as its label and its
value, then the **actions** under a divider. Pick the kind with `data-kind` (`kind` in Blade and
Vue); `field` is the default.

- **`data-kind="title"`** is the card's title, such as the order number, with no label.
- **`data-kind="actions"`** holds the row's buttons, last on the card, with no label. From 768px
  up they sit at the start of their cell, under the column header.
- **`data-numeric`** (`numeric`) aligns numbers to the end of a table cell, with figures of one
  width. Put it on the column header and its cells.
- **`data-phone="hidden"`** (`hide-on-phone`, `hideOnPhone`) leaves a less important column out
  of the card and shows it from 768px up. Put it on the column header **and** on every cell of the
  column, so the headers still match the cells for a screen reader.

## Sorting, selection and the empty state

The app owns sorting, paging and selection (ADR 2); the table only
shows them.

- **Sorting:** a sortable column header takes `aria-sort` (`sort`): `none`, `ascending` or
  `descending`, with one column sorted at a time. Its label is a
  **`plinth-data-table-sort`** button (`<x-plinth::data-table-sort>`, `PlinthDataTableSort`),
  which the app listens to; its icon shows both arrows, or the one of the order. On a phone the
  sortable headers stay visible above the cards as a row of sort buttons.
- **Selection:** a table whose rows can be selected puts `aria-selected` on every row (`selected`),
  `true` on the selected ones. A selected row takes the selection tint and an accent edge at its
  start. The control that selects it is the app's.
- **The empty state:** one `plinth-data-table-empty` row in the body, whose cell spans every
  column (`columns`).
- **Paging** controls sit outside the table.

## Blade

<Source
  language="html"
  dark
  code={`<x-plinth::data-table caption="Orders">
  <x-slot:head>
    <x-plinth::data-table-column>Order</x-plinth::data-table-column>
    <x-plinth::data-table-column :sort="$sort === 'date' ? $direction : 'none'">
      <x-plinth::data-table-sort wire:click="sortBy('date')">Date</x-plinth::data-table-sort>
    </x-plinth::data-table-column>
    <x-plinth::data-table-column numeric>Total</x-plinth::data-table-column>
    <x-plinth::data-table-column>Actions</x-plinth::data-table-column>
  </x-slot:head>
  @forelse ($orders as $order)
    <x-plinth::data-table-row wire:key="order-{{ $order->id }}">
      <x-plinth::data-table-cell label="Order" kind="title">{{ $order->number }}</x-plinth::data-table-cell>
      <x-plinth::data-table-cell label="Date">{{ $order->date }}</x-plinth::data-table-cell>
      <x-plinth::data-table-cell label="Total" numeric>{{ $order->total }}</x-plinth::data-table-cell>
      <x-plinth::data-table-cell kind="actions">
        <x-plinth::button variant="secondary" size="sm" :href="route('orders.show', $order)">View {{ $order->number }}</x-plinth::button>
      </x-plinth::data-table-cell>
    </x-plinth::data-table-row>
  @empty
    <x-plinth::data-table-empty :columns="4">No orders yet.</x-plinth::data-table-empty>
  @endforelse
</x-plinth::data-table>`}
/>

`sort` and `kind` take the `DataTableSort` and `DataTableCellKind` enums or their values; an
unknown sort falls back to `none` and an unknown kind to `field`.

## Tokens

- **`--plinth-data-table-row-height`** is a body row's height in the table layout (44px).
- The cards use `color.surface-raised`, `color.border` and `radius.container`, like the
  [list card](?path=/docs/components-list-card--docs); a selected row uses `color.accent-subtle`
  and `color.accent`.
