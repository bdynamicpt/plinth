# Avatar

A person or an organisation, at a glance: in a list of people, on a comment, in the account menu.
It shows an image when there is one, then initials, then a person glyph.

## Image, initials, glyph

Give it an `src` for a photo or logo. Without one it shows **initials**, taken from the `name`:
the first letter of the first and the last word (_Ana Lima_ → _AL_, _Zé_ → _Z_). Pass `initials`
when the name doesn't give good ones, as for an organisation. With neither, it shows the glyph.

## The name, and when it is decorative

An avatar always says whose it is: the `name` becomes its accessible name, read by screen readers,
with any status after it (_Ana Lima, Online_). Blade refuses to render an avatar without a name,
and Vue warns.

When the name is printed right next to the avatar, as in a list row, set **`decorative`**: the
avatar is then hidden from screen readers, so they don't read the name twice. Its status is
hidden too, so if it has one, say it in the visible text beside it (_Ana Lima · Online_).

<Canvas of={AvatarStories.Decorative} />

## Status

A small dot at the bottom corner, in one of the badge's tones: success for online, warning for
away, danger for busy, neutral for offline. Always give it a `statusLabel` (_Online_): colour alone
doesn't say what it means, and the label joins the accessible name. Blade refuses a status without
a label, and Vue warns. The dot's ring takes the page colour; on a card, set
`--plinth-avatar-ring: var(--plinth-color-surface-raised)` on the card.

## Sizes

**sm** (24px) inline with text and in dense tables, **md** (32px, the default) in lists and on
comments, **lg** (40px) in headers and the account menu, **xl** (56px) on a profile.

<Canvas of={AvatarStories.Gallery} />

## Shape

Round by default (`--plinth-radius-pill`). A brand that prefers squares changes that token, and
every avatar follows: switch **Brand** in the toolbar to see it.
